## ✅ How to [Activate WinRAR with the Latest Trial Version](https://gist.github.com/devomman/43b6d863a102387c01cb0159f230d5e6) For Windows User

1. **Download and Install WinRAR:**
   - Visit the official website: [Download WinRAR](https://www.rarlab.com/download.htm)
   - Download the latest trial version and install it on your system.

2. **Create the `rarreg.key` File:**
   - Open **Notepad** and paste the following registration code:


     ```
      RAR registration data
      RARLAB
      Unlimited WinRAR® Licence
      UID=5b1f63c63f710b3b2c10
      64122122502c1007b8e18655fd48d2ff3c927a80b1068d7d0bd937
      73e43dfe14ad087d2b45607d91658d4363a394a93dfbabb6eac789
      d5625486b59124687fce2beb203a61dc2271dd181018b28b0fb8b5
      63c2061f601a0388cf1307f790ada1e4fc60a60f1889acb89168cc
      68ea2c601b7a026a86ea5afe24843025ac2d23132a474600a0b4b6
      87c5600ca41f25e2ba212ea28b3a75f83ce3b4af03a0803b609135
      91ba6bfcb4ee2522d0be3ec12847e924bb8f51a52b750213983979
     ```
- Save this file name as `rarreg.key`

3. **Navigate to the WinRAR Installation Folder:**
   - Press `Windows Key + R` to open the Run dialog.
   - Type `%ProgramFiles%\WinRAR` and press Enter.

4. **Paste the `rarreg.key`:**
   - In the WinRAR folder, paste the `rarreg.key` file you created.

5. **Enjoy WinRAR:**
   - You're all set! The trial version will now be activated.
